# 📦 منظومة فرز بوليصات بوسطة وتجهيز الطباعة الحرارية
### Bosta Shipping Labels Smart Sorter & Thermal Resizer (75mm × 125mm)

تطبيق ويب حديث ومتكامل أحادي الصفحة (Single-Page Application) مخصص لمستودعات التجارة الإلكترونية وفرق تجهيز الشحنات (Picking & Packing)، يعمل بنسبة **100% من جانب العميل (Client-Side)** دون الحاجة لأي خادم أو اتصال خارجي، وجاهز للاستضافة الفورية والمجانية على **GitHub Pages**.

---

## 🎯 الأهداف والمميزات الأساسية

1. **استخراج ذكي للنصوص العربية من بوليصات بوسطة (Bosta AWBs)**:
   - قراءة وتحليل ملفات الـ PDF المجمعة الصادرة من لوحة تحكم بوسطة عبر `pdf.js`.
   - استخراج بيانات الموديل، اللون، المقاس، والكمية بدقة تحت قسم `"وصف الشحنة"`:
     - مثل: `طقم الاميرات اطفالي - كشميري / الثالث (QTY 1)`
     - مثل: `سجادة صلاة قطيفة مطبوعة - الأقصى (QTY 3)`
   - استخراج وتحديد أكواد الـ SKU من قسم `"ملاحظات"` (مثل `ba014e2`, `eb033x0`, `Ac055ca4`).

2. **التسوية الذكية للغة العربية (Arabic Normalization)**:
   - إزالة التشكيل وحركات المد والتطويل (الكشيدة).
   - توحيد الهمزات والألفات (`أ, إ, آ -> ا`)، والتاء المربوطة (`ة -> ه`)، والياء والألف المقصورة (`ى -> ي`).
   - ترتيب منطقي للمقاسات العربية (`الأول ← الثاني ← الثالث ← الرابع`) والإنجليزية (`S ← M ← L ← XL`).

3. **استراتيجيات الفرز الثلاث (Sorting Strategies)**:
   - **الخيار (أ) - نظام التجهيز السريع (موصى به)**:
     - تجميع كافة طلبات **الموديل الواحد (Single-Model Orders)** أولاً، وفرزها أبجدياً حسب اسم الموديل ← اللون ← المقاس.
     - تجميع طلبات **الأصناف المتعددة (Multi-Model Orders)** في نهاية الملف لمعالجتها في محطة التجميع المنفصلة.
   - **الخيار (ب) - فرز موحّد لكافة الشحنات**:
     - ترتيب كافة البوليصات بحسب المنتج الأول المذكور بالوصف.
   - **الخيار (ج) - فرز بحسب كود الـ SKU أو شيت المخزون**:
     - مطابقة الأكواد مع ملف إكسيل مرفوع (`inventory_export.xlsx`) وترتيبها حسب أولوية المستودع.

4. **تغيير مقاس الصفحات للطباعة الحرارية (75×125 ملم)**:
   - تحويل مقاس الصفحات إلى المقاس الحراري القياسي: **Width = 75 mm, Height = 125 mm** (`212.60 pt × 354.33 pt`).
   - خيار الحفاظ على أبعاد الباركود وتوسيطه (`keepAspectRatio: true`) أو التمدد لملء الصفحة كأداة PDF24.
   - الحفاظ التام 100% على دقة الخطوط ومتجهات الباركود ورمز الـ QR دون أي بكسلة (Vector Quality) عبر `pdf-lib`.

5. **أمان تام وسرعة فائقة**:
   - كافة العمليات تتم محلياً في ذاكرة متصفحك دون رفع أي بيانات أو بوليصات لسيرفرات خارجية.

## 🚀 طريقة الاستضافة على GitHub Pages

1. قم بإنشاء مستودع جديد على GitHub (مثلاً: `bosta-labels-sorter`).
2. ارفع ملفات المشروع (`index.html`, مجلد `js`, مجلد `css`, `README.md`).
3. انتقل إلى **Settings** > **Pages** داخل المستودع.
4. تحت قسم **Build and deployment**:
   - Source: اختر `Deploy from a branch`.
   - Branch: اختر `main` واجعل المجلد `/ (root)`.
   - اضغط **Save**.
5. سيعطيك GitHub رابطاً مباشراً للتطبيق يعمل على كافة أجهزة الكمبيوتر والجوالات.

---

## 🖨️ إعدادات الطابعات الحرارية (Thermal Printers)

عند طباعة الملف الناتج:
1. اختر في إعدادات الطابعة مقاس الملصق: **75mm × 125mm** (أو 3 × 5 إنش).
2. اجعل التحجيم (Scale) في نافذة الطباعة: **Actual Size** (100%) أو **Fit to Printable Area**.
3. متوافق مع طابعات: Xprinter, Zebra, HPRT, Rongta, Dymo وكافة طابعات الفواتير والبوليصات.

## 📂 بنية الملفات (Architecture)

```text
├── index.html            # واجهة التطبيق التفاعلية باللغة العربية (RTL) مع Tailwind CSS
├── css/
│   └── styles.css        # التنسيقات الإضافية والخطوط وتأثيرات مناطق السحب والإفلات
├── js/
│   ├── arabic-utils.js   # خوارزميات تسوية العربية واستخراج بنود بوسطة وأكواد الـ SKU
│   ├── excel-parser.js   # قراءة شيتات المخزون (SheetJS) وربط الأكواد تلقائياً
│   ├── pdf-processor.js  # معالجة الـ PDF عبر pdf.js والفرز وإعادة التحجيم عبر pdf-lib
│   ├── demo-data.js      # مولد بيانات بوسطة التجريبية للاختبار الفوري بضغطة زر
│   └── app.js            # إدارة الواجهة والتفاعل والجدول التفاعلي والتحميل
└── README.md             # دليل التثبيت والاستخدام
```
